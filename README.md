# Numerical Methods TP

Practical exercises for the Numerical Methods course at Unige

## Structure

- `TP1/` — Practical 1
- `TP2/` — Practical 2
- `TP3/` — Practical 3

## Topics

The repository contains implementations of numerical methods studied
during the course, including topics such as:

- Linear algebra
- Matrix operations
- Numerical algorithms
- Error analysis
- Numerical approximations

## Tools

- Python
- Numpy
- Matplotlib
